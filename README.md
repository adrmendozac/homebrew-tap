# adrmendozac/tap

Homebrew formulae by adrmendozac.

```sh
brew install adrmendozac/tap/thinnercore
```

| Formula | What it does |
|---|---|
| [thinnercore](https://github.com/adrmendozac/ThinnerCore) | Removes Intel slices from Universal Binary apps on Apple Silicon, safely. Version 0.1.0 is the read-only dry-run scan: it reports what thinning would remove and changes nothing. |

Requires an Apple Silicon Mac on macOS 13 or later. Homebrew builds it from
source with Swift, which takes about a minute.
